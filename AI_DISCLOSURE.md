# AI Disclosure

AI-assisted development tools were used during the development of this project.

AI assistance was used for:
- Brainstorming and refining the retrieval architecture.
- Assisting with implementation and debugging of individual components.
- Reviewing code structure and suggesting improvements.
- Assisting with documentation and presentation preparation.

The final system was locally executed, tested, evaluated, and integrated by the project team. Retrieval components, query understanding, hybrid retrieval, filtering, reranking, evaluation pipelines, and the final submission workflow were reviewed and validated against the project requirements.

The AI tools were used as development assistance and did not replace the project's testing, evaluation, or final technical decisions.
